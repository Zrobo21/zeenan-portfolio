# Sound Files Go Here

This folder needs exactly 3 files for the site's sound effects to work:

- click.mp3   — plays on button/nav/card clicks
- hover.mp3   — soft blip when hovering nav links or cards
- notify.mp3  — plays once when a new section scrolls into view

The site works perfectly fine with NO sound files present — it just stays
silent. Once you drop these 3 files in here with these exact names, sound
turns on automatically. No code changes needed.

## Where to get free, copyright-free sound files

1. Pixabay Sound Effects — https://pixabay.com/sound-effects/
   Search: "UI click", "UI hover", "notification pop"
2. Mixkit — https://mixkit.co/free-sound-effects/
   Look under the "Interface" category for crisp, short UI sounds
3. Freesound.org — https://freesound.org
   Filter by CC0 license for no-attribution-needed files

## Requirements for each file

- Keep each file under 2 seconds long (longer sounds feel laggy/annoying
  when they fire on every click)
- MP3 format, file size ideally under 100KB each
- Rename exactly to: click.mp3, hover.mp3, notify.mp3 (lowercase, no spaces)

Visitors can mute all sound anytime using the speaker icon in the top nav —
their choice is remembered on their device for future visits.
